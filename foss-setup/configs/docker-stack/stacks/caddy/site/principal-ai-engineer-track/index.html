Post-Training: SFT → RL → Distillation

MODULE 06

Inference & Serving

Where cost-per-token is decided. Your llama.cpp intuition transfers; the professional layer is vLLM and SGLang. Rule of thumb from 2026 benchmarks: SGLang's RadixAttention wins on prefix-heavy agent traffic (repeated system prompts and tool defs), vLLM remains the flexible high-throughput default, and the gap narrows as models get bigger.

vLLM docs

PagedAttention, continuous batching, the OpenAI-compatible server. Deploy it once on a rented GPU and half the serving vocabulary becomes concrete.

Localfree · docs · weekend
SGLang

RadixAttention prefix caching, structured output, speculative decoding — built for exactly the agent workloads your factory generates. Benchmark it against vLLM yourself; that memo is a Month 3 artifact.

Localfree · repo + docs · weekend
TensorRT-LLM

The maximum-performance NVIDIA path. Know what it buys and what it costs in flexibility — a build-vs-buy conversation you'll have eventually.

Workfree · repo · awareness
